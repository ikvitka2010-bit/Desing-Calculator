# UX/UI Calculator

Калькулятор вартості UX/UI-проєкту. Один файл `index.html`, без залежностей і збірки (шрифт Golos Text підтягується з Google Fonts).

Дизайн: Kvitka Design System, темна тема.

## Що вміє

- Формула: `Ціна = max( (Σ модулів + PM + буфер) × Кс × Кт × Кн × ставка + фікс. витрати, мінімальний чек )`
- Модулі з редагованими нормами годин (база + години на екран/конкурента)
- Коефіцієнти складності (Кс), терміновості (Кт) і нюанси (Кн), усі налаштовуються
- Валюти: USD / EUR / UAH
- Довідник термінів і розшифровка формули

## Запуск

Відкрий `index.html` у браузері.
